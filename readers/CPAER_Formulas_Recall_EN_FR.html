ADF · VOR · DME · intercepts / Interceptions22

Repère / LabelEnglishFrançais
Conventions
ENMH = magnetic heading; RB = clockwise relative bearing from nose; BTS/BFS = bearing TO/FROM station. Use one north reference throughout.
FRMH = cap magnétique; RB = gisement horaire depuis le nez; BTS/BFS = relèvement VERS/DEPUIS la station. Même référence nord pour tous les angles.
Wrap / Normaliser
ENwrap(x) = x modulo 360; add/subtract 360 until 0–359°. North may be written 000° or 360°.
FRwrap(x) = x modulo 360; ajouter/soustraire 360 pour obtenir 0–359°. Nord : 000° ou 360°.
BTS = MH + RB
ENBTS = wrap(MH + RB). MH 350°, RB 040° → BTS 030°.
FRBTS = wrap(MH + RB). MH 350°, RB 040° → BTS 030°.
BFS = BTS ±180
ENBFS = wrap(BTS +180°). BTS 030° → BFS 210°: aircraft southwest of station.
FRBFS = wrap(BTS +180°). BTS 030° → BFS 210° : avion au sud-ouest de la station.
RB = BTS − MH
ENRB = wrap(BTS − MH). BTS 020°, MH 080° → RB 300° (60° left of nose).
FRRB = wrap(BTS − MH). BTS 020°, MH 080° → RB 300° (60° à gauche du nez).
MH = BTS − RB
ENMH = wrap(BTS − RB). BTS 100°, RB 250° → MH 210°.
FRMH = wrap(BTS − RB). BTS 100°, RB 250° → MH 210°.
ADF card / Rose
ENFixed card: read RB. Movable card: set current MH under index to read magnetic BTS. RMI: correctly referenced needle head = BTS, tail = BFS.
FRRose fixe : lire RB. Rose mobile : afficher MH à l’index pour lire BTS magnétique. RMI correctement référencé : pointe = BTS, queue = BFS.
Turn / Virage
ENAt essentially unchanged position, right turn +30° → RB decreases 30°; left turn → RB increases. BTS stays nearly unchanged.
FRÀ position pratiquement constante, virage droite +30° → RB diminue de 30°; gauche → RB augmente. BTS reste presque constant.
Homing ≠ tracking
ENRB 000° points the nose at the station. In crosswind, holding RB 000° gives a curved homing path. Tracking needs wind correction.
FRRB 000° pointe le nez vers la station. Par vent traversier, maintenir RB 000° produit une trajectoire courbe. Suivre une route exige une correction de dérive.
VOR radial
ENRadial = bearing FROM station. On R-090: outbound course 090°; inbound course 270°. Identify aid and north reference (true-reference exceptions exist in Canada).
FRRadiale = relèvement DEPUIS station. Sur R-090 : route éloignement 090°; rapprochement 270°. Identifier aide et référence nord (exceptions au nord vrai au Canada).
TO / FROM
ENWith CDI centred: selected course toward station → TO; reciprocal → FROM. Flag describes selected-course geometry, not aircraft heading or actual travel.
FRCDI centré : route sélectionnée vers station → TO; réciproque → FROM. Le drapeau décrit la géométrie sélectionnée, pas le cap ni le déplacement réel.
30° intercept setup
ENC = desired direction of travel, NOT always radial. Choose H = C ±30° toward the course line. Sketch station, current BFS and target line first; heading alone cannot select the side. No-wind examples below.
FRC = route désirée, PAS toujours radiale. Choisir H = C ±30° vers la ligne. Dessiner station, BFS actuel et ligne cible; le cap seul ne donne pas le côté. Exemples sans vent ci-dessous.
Capture: inbound
ENAt capture BTS = C; RB = wrap(C − H). H=C+30 → RB330; H=C−30 → RB030. Start rollout with appropriate lead.
FRÀ l’interception BTS = C; RB = wrap(C − H). H=C+30 → RB330; H=C−30 → RB030. Anticiper la sortie du virage.
Capture: outbound
ENAt capture BTS = wrap(C+180); RB = wrap(C+180−H). H=C+30 → RB150; H=C−30 → RB210.
FRÀ l’interception BTS = wrap(C+180); RB = wrap(C+180−H). H=C+30 → RB150; H=C−30 → RB210.
Inbound example
ENAircraft west-northwest of NDB (BFS285), intercept C090 inbound: H120 toward line. At capture BTS090, RB330. Turn left toward 090, then correct wind.
FRAvion au ouest-nord-ouest du NDB (BFS285), intercepter C090 en rapprochement : H120 vers ligne. À l’interception BTS090, RB330. Virer gauche vers 090, puis corriger le vent.
Outbound example
ENAircraft northeast (BFS045), intercept C090 outbound: H120. At capture BFS090, BTS270, RB150. Turn left toward 090, then correct wind.
FRAvion au nord-est (BFS045), intercepter C090 en éloignement : H120. À l’interception BFS090, BTS270, RB150. Virer gauche vers 090, puis corriger le vent.
Wind trap / Vent
EN30° is a chosen training intercept, not a universal rule. Wind changes the ground intercept angle. Always compute capture RB from actual heading; after capture fly the wind-corrected heading.
FR30° est un choix pédagogique, pas une règle universelle. Le vent modifie l’angle au sol. Calculer RB à partir du cap réel; après interception appliquer la correction de dérive.
Cross-track distance
ENLateral offset = ground range × sin(angular error); small angle ≈ range × error°/60. At 30 NM, 4° → about 2 NM.
FRÉcart latéral = distance horizontale × sin(erreur angulaire); petit angle ≈ distance × erreur°/60. À 30 NM, 4° → environ 2 NM.
VOR dots
ENConventional VOR CDI: normally 2° per dot, ±10° full scale. Two dots at 30 NM ≈ 2 NM. LOC and GNSS scales differ; check equipment/mode.
FRCDI VOR classique : normalement 2° par point, ±10° pleine échelle. Deux points à 30 NM ≈ 2 NM. Échelles LOC/GNSS différentes; vérifier équipement/mode.
DME geometry
ENSlant NM = √(ground NM² + height NM²); height NM = height above station(ft)/6076. Over station at 6076 ft above it → about 1 DME, not zero.
FRDistance oblique NM = √(distance horizontale NM² + hauteur NM²); hauteur NM = pieds au-dessus station/6076. À la verticale à 6076 ft au-dessus → environ 1 DME, pas zéro.
DME ground range
ENGround NM = √(DME² − height NM²). DME 5 NM, height 6076 ft → √24 ≈4.90 NM. DME speed/time meaningful toward/away from station; unreliable for along-track speed on an arc.
FRDistance horizontale NM = √(DME² − hauteur NM²). DME 5 NM, hauteur 6076 ft → √24 ≈4,90 NM. Vitesse/temps DME pertinents vers/depuis station; pas la vitesse le long d’un arc.
30° closing time
ENFor a 30° GROUND-track intercept: closing speed = GS × sin30 = GS/2. Time(min)=120 × lateral NM/GS. 2 NM off at 120 kt → 2 min. Wind-correct heading to obtain that ground track.
FRInterception à 30° de ROUTE SOL : vitesse de rapprochement = GS/2. Temps(min)=120 × écart NM/GS. Écart 2 NM à 120 kt → 2 min. Corriger le cap pour obtenir cette route sol.

FRVs sous charge = Vs × √n; Vs₂ = Vs₁√(W₂/W₁)
VREF definition / Définition
ENLanding reference speed: the published POH/AFM speed to be maintained to 50 ft in the specified landing configuration. Use the published value; certification bases differ.
FRVitesse de référence à l’atterrissage : vitesse publiée au POH/AFM à maintenir jusqu’à 50 pi dans la configuration d’atterrissage précisée. Utiliser la valeur publiée; les bases de certification diffèrent.
VREF fallback / Calcul
ENIf VREF is not specified: 1.3 × VSO. Example: VSO 50 KIAS → VREF 65 KIAS. For approach category, use VSO at maximum certificated landing weight.
FRSi VREF n’est pas précisée : 1,3 × VSO. Exemple : VSO 50 KIAS → VREF 65 KIAS. Pour la catégorie d’approche, utiliser VSO à la masse maximale certifiée à l’atterrissage.
Weight / Masse
ENSame configuration/basis only: VREF₂ ≈ VREF₁√(W₂/W₁). POH/AFM landing-weight data takes precedence. Wind/gust additive changes the approach target, not VREF.
FRMême configuration et même base seulement : VREF₂ ≈ VREF₁√(W₂/W₁). Les données POH/AFM selon la masse ont priorité. La correction vent/rafale modifie la cible d’approche, pas VREF.
